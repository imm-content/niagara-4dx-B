# Niagara Falls 4DX — B안 (고화질·GitHub Pages 균형)

## 실행
`index.html`과 `media/` 폴더를 함께 GitHub 저장소 최상위에 업로드하세요. Settings → Pages → Deploy from a branch → main / (root).

## 구성
- 실제 나이아가라 폭포 영상 6개 (H.264 MP4, 브라우저 스트리밍용 faststart)
- `media/niagara.glb` (웹용 경량 3D 모델)
- 6막 자동재생, 음향 합성, 물안개/물방울, 화면 흔들림, 지원 기기 진동, 3D 회전/확대, 전체화면

## 품질 및 한계
- 영상 1,2,3,6: 최대 1920px 폭, 4,5: 1280px 폭. 원본 4K는 별도 보관하세요.
- 3D는 원본 `niagara.glb`(약 140MB)가 아닌 이전 웹 최적화 모델(약 21MB)을 `niagara.glb`라는 이름으로 사용합니다. 원본 대비 지오메트리 세부 정보가 줄었을 수 있습니다.
- 웹 브라우저만으로 실제 바람·물 분사·모션체어는 구현되지 않습니다. 진동 API는 일부 Android 브라우저에서만 지원됩니다.
- 3D 모드에 인터넷 연결이 필요합니다(Three.js CDN).
- 파일명 대소문자 구분, `media` 폴더 유지.
- 공개 배포 전 모든 동영상과 GLB의 라이선스 및 재배포 허용 여부 확인 필요.

## 주의
- GitHub 웹 업로드 파일당 25MiB 이하를 목표로 구성했습니다.
- 원본은 반드시 별도로 백업하세요. 본 패키지는 배포용입니다.
